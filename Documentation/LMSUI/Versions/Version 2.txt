5. Page Module Pattern

Every page must expose only one public method.

window.LoginPage = (function () {

    function initialize() {

    }

    return {

        initialize

    };

})();

PageRegistry.register("login", LoginPage);

Page files never contain business logic.

Page files never call APIs.

Page files never contain validation.

They only:

Initialize the page
Focus controls
Register events
Register themselves with PageRegistry

8. Page Registration

Every page must register itself.

Example

PageRegistry.register("login", LoginPage);

PageRegistry.register("register", RegisterPage);

PageRegistry.register("forgot-password", ForgotPasswordPage);

PageRegistry.register("reset-password", ResetPasswordPage);

PageRegistry.register("change-password", ChangePasswordPage);

PageRegistry.register("dashboard", DashboardPage);

The page name must match the value supplied by MVC.

Example

ViewData["Page"] = "login";

9. MVC Page Requirement

Every MVC view must define the page identifier.

Example

@{
    ViewData["Page"] = "login";
}

This allows PageRegistry to determine which page module to initialize.

11. Authorization Attributes

Every HTML element can now use authorization attributes.

data-auth

data-anonymous

data-role

data-permission

Examples

<div data-auth>

<div data-anonymous>

<li data-role="Administrator">

<button data-permission="Course.Create">

Layout automatically hides or removes unauthorized controls.

No manual checks are required throughout the application.

15. Debugging Lessons Learned

During development, the following standards were established:

Always verify JavaScript file paths in the browser.
Ensure config.js loads before any module that depends on AppConfig.
Export every public method from JavaScript modules (for example, initialize from Layout).
Use the browser console (typeof ModuleName) to verify modules are loaded.
Register every page before calling PageRegistry.initialize().
Load app.js after all core and feature scripts.
Match ViewData["Page"] exactly with the registered page name.

These practices help quickly isolate startup and initialization issues.
