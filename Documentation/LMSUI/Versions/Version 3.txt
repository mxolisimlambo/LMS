api.js

Examples

register()

forgotPassword()

Responsible for

Processing responses

events.js

Examples

Change Password

validation.js

Responsible only for validation.

Returns

{
    valid,
    errors
}

Validation occurs before Service is called.

ui.js

Responsible only for UI.

Loading

Success

Errors

Validation

Focus

Clear Forms

Never calls APIs.

17. Lessons Learned

During development we established several permanent standards.

Always verify JavaScript file paths.

Always export public methods from modules.

Always load config.js before dependent modules.

Always load app.js after every module.

Always match ViewData["Page"] with PageRegistry.

Never initialize pages manually.

Always use browser Network and Console tabs before changing code.

Always confirm module loading with:

typeof Layout

typeof PageRegistry

typeof LoginPage

typeof AppConfig

Always ensure Layout returns

initialize

from its public interface.

When using async startup, prefer:

Layout.initialize()

.then(...)

.catch(...)

This proved more reliable across browsers than awaiting directly inside the jQuery ready callback.
