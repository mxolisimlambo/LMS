Then update security.js so that you never hardcode permission strings.

Instead of:

SecurityService.hasPermission("Course.Create")

you'll write:

SecurityService.hasPermission(
    PermissionConstants.Course.Create
);

or

if (SecurityService.hasPermission(PermissionConstants.Student.View)) {

    // ...
